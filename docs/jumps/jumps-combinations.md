# {{ $frontmatter.title }}

Two jumps, no break in between. From Chapter 8 of *The Complete Book of Figure Skating*: a combination links two jumps so closely that the first jump never really gets its own landing glide — its landing edge goes straight into the second takeoff. This is a short section of the book (a single page), and this file covers all of it: the combination itself, the common pairings, what goes wrong, and the jump sequence.

::: tip The combination rule
The **landing foot of the first jump is the takeoff foot for the second jump** — with **no turn and no change of foot in between**. If a turn or a change of foot occurs between the jumps, the book is blunt about it: the combination is **not legal**.
:::

::: info Which rotation are these pages written for?
All descriptions in the book — and in all six Jumps files — assume a skater rotating **left / counter-clockwise**. Skaters who rotate to the right reverse the starting foot and the direction throughout.
:::

## Combination Jumps {#combination-jumps} <Badge type="warning" text="Intermediate" />

A jump combination **links two jumps together by using the landing foot of the first jump as the takeoff for the second jump**. There is no step, turn, or change of foot between them — the landing of jump one *is* the preparation for jump two.

| | |
|---|---|
| **Body** | The first jump must finish in a **controlled landing with a strong checked position** — that check is what lets the second jump be executed securely. Problems start when the first jump is poorly executed, when there is **insufficient speed**, or when the **timing between the first jump and the second** is poor. And both jumps must match: a strong, high first jump followed by a weak, small second jump is the other common mistake. To be of good quality, **both jumps should be equal** — each high and well positioned, each with a strong, secure landing. |
| **Feet** | One foot links the whole element: the foot that lands the first jump takes off for the second. No change of foot is allowed between the jumps. To have enough spring into the second jump, the **knee must not bend too deeply on the landing of the first jump** — sink too far and there is nothing left to spring with. |
| **Blade** | The landing edge becomes the takeoff edge. The standard jump landing is on a **back outside edge** (see [Fundamentals](./jumps-fundamentals.md)), and that is exactly why the second jump is most commonly a **loop** or a **toe loop**: both of them take off from that back outside landing edge — the loop directly from the edge, the toe loop with its toe assist from the same foot. The one exception the book names: a **Salchow** can occasionally be used as the second jump, when the first jump is one that lands on a **back inside edge**, such as a one-footed Axel. |

#### The common combinations

Every pairing the book lists ends the same way — in a loop or a toe loop:

| First jump | + Loop | + Toe loop |
|---|---|---|
| Waltz jump | waltz / loop | waltz / toe loop |
| Salchow | Salchow / loop | Salchow / toe loop |
| Loop | loop / loop | loop / toe loop |
| Flip | flip / loop | flip / toe loop |
| Lutz | Lutz / loop | Lutz / toe loop |
| Axel | Axel / loop | Axel / toe loop |

#### Tips — building a combination

- **Each jump alone first.** With all combination jumps, make sure you can execute *each* jump of the combination with sureness and consistency before linking them.
- **Trouble in the combination? Go back.** When problems occur, return to practising the single jumps separately — the book's training tip, not a step backwards.
- **Mind the landing knee.** A controlled, checked landing on the first jump — but not a deep one. The shallow bend is what preserves the spring for jump two.
- **Build both jumps equally.** Height, position, and a strong, secure landing are required of the second jump just as much as the first — don't spend everything on jump one.
- Much of the success in combination jumps comes from **good body positions and strength resulting from off-ice conditioning**.

## Jump Sequences {#jump-sequences} <Badge type="info" text="Beyond two jumps" />

The book defines the sequence in the same breath as the combination, and just as simply: a **jump sequence is three or more jumps linked together**.

That is the whole distinction this section of the book draws — a combination is two jumps; three or more linked jumps make it a sequence. The book gives no separate pairing list, preparation, or landing instructions for sequences here: the building blocks are the same jumps, built the same way, one landing feeding the next takeoff.

#### Tips

- Build a sequence the way you build a combination: every jump in it should first be sure and consistent on its own (see the training tip on the [Combination Jumps](#combination-jumps) card).

## Combination or sequence — at a glance

| | Jumps | The link | Second / next jump |
|---|---|---|---|
| **Combination** | 2 | Landing foot of jump 1 = takeoff foot of jump 2; **no turn, no change of foot** between — otherwise not legal | Most commonly a **loop** or a **toe loop**; occasionally a Salchow if jump 1 lands on a back inside edge |
| **Sequence** | 3 or more | Jumps linked together, one after the other | Built from the same jumps as combinations |
