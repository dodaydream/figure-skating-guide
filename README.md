# Figure Skating Guide

Quick-reference pages from *The Complete Book of Figure Skating* by Carole Shulman.

Built with [VitePress](https://vitepress.dev).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site is output to `dist/`.

## Content

- [Stopping](https://dodaydream.github.io/figure-skating-guide/stops) — snowplow, T-stop, hockey stop, one-foot stop (Chapter 4)
- [Stroking](https://dodaydream.github.io/figure-skating-guide/stroking) — forward/back stroking, sculling (swizzles), crossovers intro (Chapter 4)
- [Edges & Crossovers](https://dodaydream.github.io/figure-skating-guide/edges-crossovers) — the 8 edges, change of edge, forward/back crossovers (Chapter 4)
- [Turns & Footwork](https://dodaydream.github.io/figure-skating-guide/turns-footwork) — three turns, Mohawks, Choctaws, brackets, rockers, counters (Chapter 6)
