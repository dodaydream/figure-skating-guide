# Figure Skating Guide

Quick-reference pages from *The Complete Book of Figure Skating* by Carole Shulman.

- [Stopping](stops/index.html) — snowplow, T-stop, hockey stop, one-foot stop (Chapter 4)
- [Stroking](stroking/index.html) — forward/back stroking, sculling (swizzles), crossovers intro (Chapter 4)
- [Edges & Crossovers](edges-crossovers/index.html) — the 8 edges, change of edge, forward/back crossovers (Chapter 4)
- [Turns & Footwork](turns-footwork/index.html) — three turns, Mohawks, Choctaws, brackets, rockers, counters (Chapter 6)

Each folder is a self-contained page: an `index.html` plus its `assets` folder. Keep them together when uploading.
